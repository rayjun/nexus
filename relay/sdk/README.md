# @nexus/relay-sdk

TypeScript SDK for the Nexus E2E relay protocol — **zero npm dependencies**
(Node ≥ 22 built-ins only: WebCrypto X25519, `node:crypto`
ChaCha20-Poly1305 + HKDF-SHA256).

Implemented for TypeScript/JaveScript consumers (web, desktop, CLI, bots).
The Python relay stack (`relay/relay_server.py`, `relay/relay_agent.py`,
`relay/crypto.py`) remains the reference server/agent implementation — this
SDK is the byte-for-byte compatible client-side twin.

## Compatibility

Every primitive is locked to the reference implementations:

| Primitive                      | Reference                                    |
| ------------------------------ | -------------------------------------------- |
| X25519 Ka (raw, PSK-blended)   | `relay/crypto.py` + `E2ECrypto.swift`        |
| ChaCha20-Poly1305 (IETF)       | `pynacl crypto_aead_chacha20poly1305_ietf`   |
| HKDF-SHA256 (RFC 5869)         | `crypto.py` stdlib impl + CryptoKit          |
| nonce layout                   | `seq(4B BE) ‖ channel-id(8B)`                |
| channel id                     | `SHA-256(pairing code)` first 8 bytes hex    |

Cross-validation in `test/crypto.test.mts` asserts byte-for-byte parity with
vectors generated by `relay/crypto.py` (fixed deterministic keys) — including
the exact base64 wire payload.

## Usage

```ts
import {
  KeyPair, computeSharedSecret, deriveEncKey,
  encrypt, decrypt, channelIdFromPairingCode,
} from "@nexus/relay-sdk";

// Pairing: each side knows the 8-12 char code.
const channel = channelIdFromPairingCode("K7M2P9QX");       // 16-hex

const myKeys = await KeyPair.generate();
// exchange `myKeys.publicBytes` with the peer over the channel...

const shared = await computeSharedSecret(
  myKeys.privateBytes, peerPublicBytes, Buffer.from(pairingCode),
);
const sendKey = deriveEncKey(shared, "app_to_agent");       // direction!
const recvKey = deriveEncKey(shared, "agent_to_app");

// Frame: base64(nonce ‖ ciphertext ‖ tag); nonce = seq ‖ channel.
const wire = encrypt(Buffer.from(rpcJSON), sendKey, seq++, channel);
const { sequence, plaintext } = decryptWithSeq(wire, recvKey);
```

## Layout

```
src/crypto.ts   — keys, ECDH+PSK blend, HKDF, ChaCha20-Poly1305, nonce, framing
test/           — node:test suites (run `npm test`)
```

## Run tests

```sh
npm test          # node --test --experimental-strip-types test/
```

Node `--experimental-strip-types` is used for direct TS execution; Node ≥ 22.6
required (22.6+ flag, 23.6+ / 24 stable, no flag needed).
